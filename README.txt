# Mock Chat UI

A responsive chat interface built using HTML5, CSS3 and JavaScript.

## Features
- Conversation list sidebar
- Search conversations
- Active message thread
- Send message functionality
- Simulated automatic replies
- Auto-scroll to latest message
- New chat button
- Responsive layout for smaller screens
- Static structured conversation data; no backend

## How to run
1. Keep `index.html`, `style.css` and `script.js` in the same folder.
2. Open `index.html` in Chrome, Edge or Firefox.
3. Click conversations to switch threads.
4. Type a message and press Send.
